# 📂 File Organizer

Автоматическая организация файлов в папке Загрузки (или любой другой).

## 🚀 Возможности

- Автоматическое распределение файлов по категориям
- Поддержка пользовательских правил через JSON конфиг
- Логирование всех операций
- Режим "сухого прогона" (--dry-run) для проверки
- Генерация отчетов
- Обработка дубликатов имен файлов
- Поддержка аргументов командной строки

## 📥 Установка

```bash
git clone https://github.com/yourusername/file-organizer.git
cd file-organizer
chmod +x file_organizer.py
