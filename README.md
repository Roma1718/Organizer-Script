> Автоматическая сортировка файлов в папке "Загрузки" по категориям

## 📖 О проекте

У каждого есть папка **«Загрузки»**, которая со временем превращается в цифровую свалку. Этот скрипт автоматически наводит порядок:

- 🖼️ **Изображения** → в папку `Изображения`
- 📄 **Документы** → в папку `Документы`  
- 📦 **Архивы** → в папку `Архивы`
- 🎵 **Аудио** → в папку `Аудио`
- 🎬 **Видео** → в папку `Видео`
- 💻 **Программы** → в папку `Программы`
- 👨‍💻 **Код** → в папку `Код`
- И многое другое...

### ✨ Особенности

- ✅ **Полностью на русском** — все папки создаются с русскими названиями
- ✅ **Гибкая настройка** — легко добавлять свои категории через `config.json`
- ✅ **Безопасный режим** — режим `--dry-run` показывает, что будет перемещено
- ✅ **Подробное логирование** — все действия записываются в лог-файл
- ✅ **Генерация отчетов** — создает подробный отчет о проделанной работе
- ✅ **Простой запуск** — можно запускать через BAT-файл в один клик
- ✅ **Работает с любыми папками** — не только с "Загрузками"
